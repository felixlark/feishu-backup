# 我为什么做了 `feishu-backup`

## 标题

我没有重造飞书导出工具，我只是把它做成了一个能持续跑的备份工作流

## 导语

一开始我只想把飞书知识库同步到本地，后来发现问题不在“导出”，而在“工作流”。

## 文章结构

### 起点

- 已经有 `feishu-docx` 这种成熟项目
- 单篇导出没有问题

### 真正的坑

- 知识库不是一篇文档，而是一整棵空间树
- 网络和权限问题会让长时间任务中断
- 没有断点续传就会重复跑
- 本地如果没有归档规则，最后还是一团乱

### 我做的事情

- 加上 OAuth 和批量遍历
- 增加文档级 resume-state
- 增加实时进度和备份报告
- 增加本地落盘和定时运行

### 最终定位

`feishu-backup` 不是新的导出引擎，而是 `feishu-docx` 之上的 workflow layer。
